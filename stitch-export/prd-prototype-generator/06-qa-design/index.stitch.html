Test Design: Combat System Revision v1.2

This document outlines the test cases generated based on Combat_Design_Doc_v1.2.pdf and Damage_Scaling_Tables.xlsx. The focus is on standard coverage for core combat mechanics.

1. Feature Overview

The revised combat system introduces dynamic damage scaling based on character agility vs. enemy armor rating, and a new "stagger" state triggered by consecutive heavy attacks.

2. Pre-conditions

  • Test environment must be running game server version >= 2.4.0.
  • Test accounts equipped with baseline gear sets (ID: 4001, 4002).
  • Combat logging must be enabled (/cmd combat_log 1).

3. Test Case Matrix

TC ID Scenario Description Expected Result Priority
TC-COM-001 Basic Light Attack on unarmored target Base damage applied, no scaling penalty. High
TC-COM-002 Heavy Attack (x3) sequence Target enters "Staggered" state for 2.5s. Critical
TC-COM-003 Agility Scaling: Low Agi vs High Armor Damage reduced by calculated scaling factor (approx 45%). High
TC-COM-004 Stagger interrupt via consumable use Consumable use fails, stagger duration unaffected. Medium

4. Automated Script (Draft)

Draft API sequence for triggering the sequence programmatically:

// Invoke combat simulator macro
const player = Engine.SpawnEntity('player', { agi: 15, str: 20 });
const enemy = Engine.SpawnEntity('mob_golem', { armor: 150 });

// Execute heavy attack chain
await player.executeAction('attack_heavy', enemy);
await System.wait(800); // gcd
await player.executeAction('attack_heavy', enemy);
await System.wait(800);
await player.executeAction('attack_heavy', enemy);

// Assert state
Assert.isTrue(enemy.hasState('staggered'));
Assert.equal(enemy.getStateDuration('staggered'), 2500);
